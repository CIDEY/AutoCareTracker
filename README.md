# 🚗 AutoCare Tracker (Моё Авто)

**AutoCare Tracker** - это современное мобильное приложение для Android, разработанное в рамках курсовой работы. Оно предназначено для владельцев автомобилей, которые хотят вести детальный учет технического обслуживания своего транспортного средства.

## ✨ Основные возможности

- **🗂 Гараж (Multi-vehicle):** Поддержка управления несколькими автомобилями одновременно.
- **🛠 Учет ТО (CRUD):** Полный цикл управления записями: создание, чтение, редактирование и удаление (свайпом).
- **📈 Аналитика расходов:** Автоматический расчет суммарных затрат на каждый автомобиль.
- **🛢 Контроль замены масла:** Интеллектуальный алгоритм отслеживания интервала замены масла на основе пробега.
- **🔍 Умный поиск:** Фильтрация записей в реальном времени через SearchBar.
- **📊 Экспорт данных:** Генерация отчетов в формате CSV и возможность поделиться ими через системное окно Android (Telegram, Email и др.).
- **🎨 Современный UI:** Дизайн в стиле Glassmorphism, использование градиентов, Floating Action Button и динамических логотипов брендов.

---

## 🛠 Технологический стек

- **Язык:** C# 12
- **Платформа:** .NET MAUI (8.0)
- **База данных:** SQLite (локальное хранилище через ORM `sqlite-net-pcl`)
- **Архитектура:** MVVM (Model-View-ViewModel) с использованием `CommunityToolkit.Mvvm`
- **Внешние API:** Автоматическая подгрузка логотипов брендов через CDN
- **Навигация:** Shell Navigation (структурированная маршрутизация между страницами)

---

## 🏗 Архитектурные решения

В проекте реализованы принципы чистого кода и современного мобильного программирования:
1. **Source Generators:** Использование атрибутов `[ObservableProperty]` и `[RelayCommand]` для минимизации шаблонного кода (Boilerplate).
2. **Dependency Injection:** Регистрация всех сервисов, вью-моделей и страниц в DI-контейнере (`MauiProgram.cs`).
3. **QueryProperty:** Передача объектов между страницами при навигации (например, при редактировании записи).
4. **Custom UI:** Верстка сложных элементов управления на XAML с использованием `Grid`, `SwipeView` и кастомных теней.

## 🚀 Как запустить

1. Установите **Visual Studio 2022** с рабочим пакетом **.NET MAUI**.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/AutoCareTracker.git
   ```
3. Откройте файл решения `.sln`.
4. Дождитесь восстановления NuGet-пакетов.
5. Выберите целевое устройство (Android Emulator или реальный телефон) и запустите проект (F5).
